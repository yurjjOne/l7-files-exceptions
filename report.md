## Самоперевірка

1. `open("a.txt", "w")` для наявного файлу стирає весь вміст; дописувати — режим `"a"`.
2. `with` сам закриває файл, навіть якщо всередині сталася помилка.
3. Після `for line in f` у `line` рядок із `\n` у кінці, тому `line.strip()` перед `int()` / порівнянням.
4. `ValueError` — тип правильний, а значення ні (`int("abc")`); `TypeError` — непідходящий тип (`"5" + 5`).
5. `except:` без типу ловить усе (навіть Ctrl+C) і ховає справжню причину; треба конкретний тип або `except Exception as e` з виводом `e`.
6. Для списку словників — JSON (пам'ятає типи і вкладеність); CSV — для простих таблиць.
7. Pull Request — пропозиція влити гілку в `main` з переглядом; захист `main` не дає писати в неї напряму, тож зміни проходять перевірку і не ламають робочу версію.
8. При конфлікті: `git pull origin main` у своїй гілці, залишити потрібні фрагменти, видалити `<<<<<<<`, `=======`, `>>>>>>>`, потім `git add`, `git commit`, `git push`.
